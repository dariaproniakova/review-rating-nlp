# Data

The data is not committed to this repository.

It comes from the DAN.IT in-class Kaggle competition (`final-project-danit-ds-3-4`), which uses
customer reviews from a women's clothing e-commerce site (columns: Age, Review_Title, Review,
Pos_Feedback_Cnt, Division, Department, Product_Category, Rating, Recommended).

The notebooks expect:

```
data/rawdata/train.csv
data/rawdata/test.csv
data/rawdata/sample_submission.csv
```
